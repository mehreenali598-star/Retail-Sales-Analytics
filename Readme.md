Retail Sales Analytics Project

Project Overview

This project analyzes retail sales data using Python, SQLite, 
and Power BI to understand sales performance and generate interactive business insights.

Tools & Technologies

- Python
- Pandas
- SQLite3
- Power BI
- DAX

Data Pipeline

1. Loaded the retail dataset using Pandas.
2. Checked missing values and duplicate records.
3. Converted date columns into proper datetime format.
4. Stored the processed data in SQLite databases.
5. Validated the database records.
6. Connected the data with Power BI for interactive analysis.

Power BI Dashboard

The dashboard includes:

- Daily Sales Trends
- Total Sales by Category
- Category Details
- Interactive Slicers
- Tooltips
- Drill-through functionality
- Back Navigation
- DAX Measures

Project Outcome

The project provides an interactive view of retail sales performance and demonstrates
 an end-to-end data analytics workflow from raw data processing to database storage and business intelligence reporting.
